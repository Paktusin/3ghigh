## Сборка

```
npm test                       # ~1 мин, должно быть 0 fail
npm run build                  # image + meta + check → out/cyprus
```

- `meta` переписывает манифест `.pkg` под состав набора — **без `--keep-pkg`**,
  иначе навигация встаёт на 28 %.
- `check` (`src/setcheck.js`) и `src/checksum.js` должны сказать
  «расхождений нет» / «все суммы и размеры сходятся».
- Сборка сама гоняет эмуляторы прошивки (`litcity`, `litnear`, сверки в
  `cyplit.verify`) и падает при расхождении — не обходить, а чинить.
- Опыты собирать в отдельный каталог (`node src/mkcyprus.js out/<имя>`, затем
  `node src/mkmeta.js out/<имя>` и `node src/setcheck.js out/<имя>`), либо в
  `git worktree` в scratchpad, чтобы не трогать основное дерево.

## Сначала завод

Перед любой правкой генератора — посмотреть, как это устроено в заводских
данных (`maps/`, только чтение), и делать так же. После правки — сверка
«наш против завода» цифрами (распределения, порядок, рамки, размеры) до записи
на флешку. 23.10 под-блоки XAC, сделанные «по-своему» (полосы вместо заводских
компактных пятен), намертво повесили инициализацию на 24 %.

## Лимиты памяти — до записи на флешку

Таблица заводских максимумов — в `CLAUDE.md`. Магнитола зависает на загрузке,
если **одна загружаемая часть** (тайл XAC, тайл/кластер GDB, блок LIT) больше
заводской. Любая правка генератора, увеличивающая часть, сверяется с таблицей;
превышение — только осознанно и с пометкой в `docs/`. Числа из сборки
пересчитывать в таблицу `CLAUDE.md`.

- XAC держим **четырьмя тайлами** (`CY00`…`CY03`, `src/xacsplit.js`). Один тайл
  (240 тыс. узлов, 4,2 МБ блоков) вдвое выше заводского — пользователь его
  отверг, не предлагать.
- Упрощение дорог: Дуглас — Пекер `tol 6` (`src/mkxac.js`); в XAC нет точек
  изгиба — каждая точка становится узлом.

## SD-карта

Карта монтируется как `/Volumes/NO NAME`. Mac часто не видит её с первого
раза — ждать до 30 с, иначе попросить вставить заново.

Запись образа:
```
n=0; until [ -d "/Volumes/NO NAME" ] || [ $n -ge 30 ]; do sleep 1; n=$((n+1)); done
V="/Volumes/NO NAME"; [ -d "$V/var/ndr" ] && cp -R "$V/var/ndr/" logs/<дата>-<имя>/
tools/write_maps.sh <набор из out/> --no-wait
```
- Сначала **сохранить результаты пробы** (`var/ndr`), если они на карте, в `logs/`.
- `write_maps.sh` сам сверяет суммы, удаляет скрипт пробы (`copie_scr`) и
  извлекает карту.
- **Если пользователь просил записать образ — пробу на карте не оставлять.**
  Скрипт на карте запускается сам при вставке в машину.

Проба состояния машины: `tools/write_probe.sh` (источник —
`tools/ndrprobe/run.sh`). Только чтение (`sloginfo`, `pidin`, копии файлов);
на машине нет `grep` и `sed`; чтения, которые могут заблокироваться, — под
сторожем `guard` с лимитом.

## Машина

- Только чтение журналов и состояния. Своих процессов, клиентов, служб не
  запускать. Причины искать статикой.
- Пользователь проверяет руками и пишет коротко («вставил», «готово»,
  «не строит маршрут»). После записи образа — сказать, **что именно проверить**
  (конкретный маршрут, конкретный поиск).
- Swap `AUDIMMI3G.swap` с машины не годится (номер записи 0).
- Удаление раздела навигации на машине — обычный шаг пользователя перед
  чистой установкой.

## Разбор прошивки

Порядок: `fwmap/decomp/*.c` → Ghidra MCP (`list_strings` по строке ассерта или
имени класса → `get_xrefs_to` → `decompile_function_by_address`) → capstone
(`CS_ARCH_SH`, `CS_MODE_SH4A | CS_MODE_LITTLE_ENDIAN`), если Ghidra не создала
функцию. `VA = смещение + 0x08040000` для кода; данные от `0x09a2acd4` —
смещение = `VA − 0x08041000`.

Статистика по данным — только для проверки прочитанного в коде. Догадки,
сделанные «по цифрам», в этом проекте трижды оказывались ложными. Вывод,
что что-то «работало» на машине, брать только из слов пользователя или из
`docs/device.md`, а не из чужого пересказа.

Хороший приём — эмулятор пути прошивки на JS (`src/litcity.js`, `src/litnear.js`)
и встроить его в сверку сборки, чтобы регрессия роняла `npm run build`.

## Документация и коммиты

- Разобрал формат — записать в `docs/formats/<формат>.md` в тот же заход,
  включая **отвергнутые гипотезы с цифрами**; догадку помечать догадкой.
- `README.md` — оглавление и состояние, держать актуальным.
- Коммитить только по просьбе пользователя; перед коммитом — `/simplify`.
  Сообщения коммитов по-русски.
- `maps/` не писать никогда; опыты — клон через `cp -c`.
