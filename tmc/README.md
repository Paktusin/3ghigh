# Пробки из интернета в MMI по RDS-TMC

Подпроект: брать дорожную обстановку Кипра из интернета и передавать её в MMI 3G
High так, как это делает обычная служба TMC, — по FM-эфиру через маленький
передатчик в салоне. Машину не трогаем: никаких своих процессов на головном
устройстве, только питание передатчика от 12 В.

| файл | что там |
|---|---|
| [plan.md](plan.md) | план реализации по этапам, что от чего зависит, риски |
| [firmware.md](firmware.md) | как прошивка принимает TMC и выбирает станцию — по коду |
| [table.md](table.md) | кипрская таблица локаций: модель, генератор `src/cyptmc.js`, сравнение с заводом |
| [hardware.md](hardware.md) | железо передатчика: состав, цены, питание, антенна, мощность |

Связанное: формат таблиц `.tlt` и реестра — [../docs/formats/tmc.md](../docs/formats/tmc.md),
декодеры — `src/tlt.js`.
