# Железо передатчика

```
TomTom / HERE Traffic API ──► сервер (VPS или облачная функция)
                               событие → код события ALERT-C + код локации кипрской таблицы
                                         │ компактный список сообщений (JSON)
телефон (точка доступа) ──Wi-Fi──► ESP32 ──I²C──► QN8066 ──► провод 10–20 см у FM-антенны
                                   группы 3A + 8A
```

## Состав

| что | зачем | цена |
|---|---|---|
| ESP32 (любой DevKit) | Wi-Fi, сборка групп RDS, управление передатчиком | ~5 € |
| модуль QN8066 (библиотека pu2clr, `rdsSendGroup`) | FM-передатчик с RDS, произвольные группы | ~10–15 € |
| понижающий преобразователь 12→5 В или USB-розетка | питание; лучше от цепи, которая включается с зажиганием | ~3 € |
| провод-антенна, при необходимости аттенюатор | мощность нужна минимальная, приёмник в метре | — |
| интернет: точка доступа на телефоне | или 4G-модем с SIM, если нужна автономность | 0 / ~20 € |

Альтернатива QN8066 — Si4713 (плата Adafruit): хорошо описан буфер
произвольных групп `TX_RDS_BUFF`, мощность маленькая — для салона это плюс.

GPS и часы реального времени не нужны. **Группы 4A (время) не передавать**:
навигация принимает время от тюнера (тип пакета 1, `TME`, см.
[firmware.md](firmware.md)), чужое время может сбить часы.

## Что передаём

* PI: старшая тетрада = код страны Кипра в RDS (2), остальное — свой код
  программы. ECC Кипра — `E1` (группа 1A; так же E1 у CH, LU, DK, GB, FR в
  заводском реестре, а E2/2 — это Чехия). Оба должны совпадать с записью
  кипрской таблицы в реестре.
* 0A — PS (имя станции), чтобы станцию было видно и в радио.
* 3A — ODA: AID `0xCD46` (RDS-TMC), системная информация: LTN, SID, без
  шифрования.
* 8A — сообщения ALERT-C (одногрупповые, при нужде многогрупповые).

Пропускная способность RDS — около 11 групп/с; на TMC хватит 1–3 групп/с,
десятки сообщений повторяются каждые несколько секунд.

## Частота, мощность, антенна

* Частота — свободная от кипрских станций в месте использования; тюнер ищет
  станцию по фильтру CC/LTN сам, частоту в MMI вводить не надо.
* Мощность — минимальная, с которой фоновый тюнер уверенно принимает. Для
  маломощных FM-передатчиков в Европе ориентир — ERC Rec. 70-03 (порядка
  50 нВт ЭИИМ); проверить местные правила Кипра.
* Антенна — короткий провод рядом с антенной FM в стекле. Начинать с самой
  малой мощности и расти, пока MMI не начнёт стабильно принимать.

## Источники данных

* **TomTom Traffic API** (Incidents, Flow) — Кипр покрыт, бесплатно ~2500
  запросов/день.
* **HERE Traffic v7** — аналог, тоже с бесплатным уровнем.
* Waze for Cities — только по партнёрской программе.
