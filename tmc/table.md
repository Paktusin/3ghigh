# Кипрская таблица локаций

`src/cyptmc.js` (06.11): OSM → `out/cyp/tmc/EJ211_02_01.tlt` и реестр
`out/cyp/tmc/EJ211_global.tlt` (заводские 14 таблиц плюс Кипр). Вход —
`out/cyp/cyprus-latest.osm.pbf` (Geofabrik). Разбор модели для проверки —
`out/cyp/tmc/model.json`.

```
node src/cyptmc.js [pbf] [--out out/cyp/tmc]
```

## Модель — по образцу заводских таблиц

Сняты с LU, DE, AT, DK (`docs/formats/tmc.md`):

| loc | тип | что | ссылки |
|---|---|---|---|
| 1 | 1 | Europe | — |
| 2 | 3 | Cyprus | area 1 |
| 3… | 12 | округа (OSM admin_level 5, те, где есть точки) | area 2 |
| 100… | 21 / 22 | трасса A / дорога B: n10 номер, n14 название, n18 и n1c — концы | area 2 |
| 1000… | 37 / 45 | съезд трассы / пересечение или населённый пункт на дороге B | line, area — округ, neg/pos, x20/x24 |

* Точки одной дороги идут подряд, между дорогами пропуск в один код:
  соседи `loc ± 1` пишутся коротким кодом, как у завода.
* `x20` / `x24` — метры по оси дороги до следующей и предыдущей точки. Смысл
  снят с DE: расстояние сходится с прямым с запасом на изгибы. Это **догадка
  по данным**, кода, читающего эти поля, не читал.
* Типы точек: 37 (съезд) — у завода это самый частый тип на автобанах;
  45 — пересечение (у LU на `Chemin Repris`). Соответствие ISO 14819-3
  (P1.3, P1.11) — догадка по ряду 35…46 = P1.1…P1.12.
* Имена — латиница Latin-1 с регистром (`name:en`, иначе транслитерация
  греческого); съезд — ближайший населённый пункт и номер `(12)`.
* Ось дороги: концы — самая дальняя по прямой пара узлов, затем кратчайший
  путь по направленному графу. Отвергнуто: «самый длинный путь по графу» —
  по двум проезжим частям, сведённым на одном конце, путь уходит по одной и
  возвращается по встречной (A1 получалась 167 км вместо 85).
* Растр покрытия — весь прямоугольник (рамка точек ± 15 000, как у завода),
  все клетки закрашены.
* Словарь фрагментов имён — из заводской таблицы GB.

Проверка (`src/cyptmc.test.js`): сборка → разбор заводскими декодерами
совпадает с моделью; каждое имя использовано; ссылок в никуда нет; число
`neg` равно числу `pos`; все точки на Кипре (32,41…34,00° в. д., 34,67…35,19°
с. ш.); каталог блоков в реестре совпадает с файлом.

## Известные огрехи (v1)

* У съездов без номера и имени в OSM имя повторяется (`Agios Konstantinos &
  Elenis` ×4 на A1).
* Названия дорог B — самые частые названия улиц на них (`B1 Lemesou
  Avenue`): в городах верно, на трассе между городами — нет.
* Север острова (дороги `D.xx`) не взят.
