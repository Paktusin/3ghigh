# Кто кого вызывает

Вызовы в этой прошивке идут через таблицы указателей, поэтому в тексте
декомпиляции их не видно: `(*(code *)PTR_FUN_xxxx)()`. Чтобы найти вызывающего,
надо искать **адрес функции как 32-разрядную константу** в образе и смотреть, в
чью область он попал.

Найдено так (полная выгрузка даёт границы всех 81 973 функций):

```
xac_read_vector_v5  (0x08272938)  <- FUN_0826f300, FUN_08272ef4, FUN_082748e0
xac_find_node       (0x08272350)  <- FUN_082707e8, FUN_082724a0, xac_read_vector_v5
xac_decode_coord    (0x082727e8)  <- xac_read_vector_v5
```

`FUN_08272ef4` оказалась обёрткой на один вектор: читает запись и раскладывает
её в структуру для вызывающего. Обходчик всех векторов блока — в другом месте,
кандидаты `FUN_0826f300` и `FUN_082748e0`.
