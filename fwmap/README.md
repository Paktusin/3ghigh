# Карта прошивки

Проект Ghidra (`fw/ghidra/p.gpr`, 1.4 ГБ) в git не попадает, поэтому результаты
разбора хранятся здесь — в виде, который переживёт и чистку временных папок, и
пересоздание проекта.

* `names.tsv` — адрес, имя, чем опознана. Применяется скриптом `ApplyNames.java`,
  который при надобности сам создаёт функцию по адресу.
* `decomp/` — декомпилированные куски, на которые опираются наши читатели.
  Не весь образ, а только разобранное: `xac.c`, `lit.c`, `gdb.c`, `poitile.c`,
  `next.c` (итератор LIT), `load.c`, `f48.c`.
* `scripts/` — headless-скрипты:
  * `LitAnalyze.java` — дизассемблировать диапазон, проанализировать и выгрузить
    все функции в нём. Нужен потому, что анализ по диапазону в ряде областей
    функций не создаёт.
  * `LitOne.java` — то же для одной функции по точному адресу.
  * `DumpAll.java` — выгрузить все функции проекта.
  * `ApplyNames.java` — проставить имена из `names.tsv`.

Адреса: `VA = смещение в файле + 0x08040000` (ELF `LOAD vaddr=08040000 off=0`).

Запуск, например:

```
support/analyzeHeadless <проект> <имя> -import out/ndr/MMI3GApplication \
  -noanalysis -scriptPath fwmap/scripts -postScript LitAnalyze.java 0x08272000 0x08273400 out.c
```
