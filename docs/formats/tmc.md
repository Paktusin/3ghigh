# TMC

## TMC

Реестр таблиц локаций лежит в `EJ211_global.tlt`: метка `TMC-LOC-TABLE OV`,
u16 BE число записей по 0x1A, записи по 36 байт с 0x20.

| Смещение | Значение |
|---|---|
| +0x04 | ISO-код страны, 2 байта |
| +0x06 | u8 ECC, расширенный код страны RDS |
| +0x07 | u8 код страны RDS |
| +0x08 | u8 LTN, номер таблицы локаций |
| +0x1C | код языка, 2 байта |

Имена файлов таблиц: `<ПРЕФИКС>_<код RDS>_<LTN>.tlt`. В европейском наборе
27 таблиц на 22 страны, у России шесть.

## TMC для Кипра (19.10)

* В заводском реестре (`EJ211_global.tlt`) 27 таблиц на 22 страны — **Кипра
  нет**. Публичной таблицы локаций Кипра (ISO 14819-3, CID/TABCD) и службы
  RDS-TMC на Кипре поиск не нашёл (OSM wiki «TMC/Location Code List» Кипра не
  знает). Значит дорожных сообщений по FM на Кипре MMI не получит, какую бы
  таблицу мы ни собрали; онлайн-трафика у MMI 3G нет.
* Компонент `TMC` (6,7 МБ) кладём заводским: таблицы читает фаза 2
  инициализации DBM (docs/device.md), без компонента — риск для старта, а
  выигрыш в объёме мал.
* Собирать свою таблицу имеет смысл, только если появится служба TMC на Кипре.

### Что внутри компонента `TMC` (MMI3G, 19.10)

Контейнер FLDB `kN221EUx01t01.db`, 15 записей: реестр `EJ211_global.tlt` и 14
таблиц локаций `EJ211_<CC>_<LTN>.tlt` (CZ, CH, IT, BE, LU, NL, DK, AT, GB, DE,
ES, SE, FR, NO; «27 таблиц на 22 страны» выше — это `TMC3GP` для 3G+).
Строка реестра: ISO, ECC, CC (страновой код RDS из PI), LTN (номер таблицы),
язык. Таблица начинается меткой `TMC-LOC-TABLE BR` и строкой
`!14!TLT 7_1 with 1 raster!41!`, дальше — сжатые двоичные данные (не разобраны):
по смыслу это коды локаций ALERT-C с привязкой к дорогам карты.

**Частот там нет.** Станцию с TMC приёмник находит сам: страна и таблица
приходят в RDS (CC в коде PI, ECC, LTN в системной информации TMC), и MMI ищет
в реестре таблицу с такими CC/ECC/LTN. `TMCConfig.dat` (в образ не кладём) —
строки вида `4;2;64;15;30;62;15;32;62;` и `SEK=1`; по виду — настройки служб по
странам/таблицам, `SEK` — похоже, ключ шифрованных служб (TMCpro). Догадка, не
разбиралось.

Если на Кипре появится служба: нужна её таблица локаций (от оператора) и своя
`.tlt` с привязкой к нашим дорогам XAC — формат тела `.tlt` ещё не разобран.
