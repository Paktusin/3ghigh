# Разбор навигационной базы MMI 3G / 3G+

Реверс-инжиниринг формата навигационных данных Audi/VW MMI 3G(P) (вендор Becker
Automotive). Всё получено чтением файлов; оригиналы никогда не изменялись.

Разобранный набор: **8R0060884KL, ECE 6.36.0, «EUR 2023»**, 22 ГБ.
Для сверки привлекался второй набор: 8R0060884HS, ROW 5.13.4, покрытие
Австралия и Новая Зеландия (VW Touareg RNS 850).

## Что осталось изучить по каждому типу файла

Список задач, чтобы не переспрашивать. Столбец «зачем» отвечает, что сломается

### Дорожный тайл `.xac`

| что изучить | зачем | с чего начинать |
|---|---|---|
| правило разбиения на группы в границах `+0x7c…+0x88` шапки | заполнять шапку многоблочного тайла своими числами, а не нулями | значения — накопленные размеры блоков (сходится у всех 6943 тайлов с блоками); неизвестно, что кладёт блок в группу |
| нужен ли Кипру парный тайл слоя `_2` | тайлы в базе ходят парами `_1` + `_2` (3568 пар, непарных нет) | посмотреть, чего требует реестр `XAC-STRUKTUR` |
| раскладка имён между ключами в `ZE-NAMEN` | перечислить все имена тайла, а не каждое шестнадцатое | имя по смещению ключа читается всегда (987 412 из 987 412); между именами лежат байты `0x00`/`0x04`/`0x05`, которых распаковщик не знает |
| смысл слова на имя (`+0x28`) и трёх байт на имя в `ZE-NAMEN-MMI` | вид имени и подпись на экране | старший байт слова — номер вида (0…7), младший у 96.6 % имеет вид `0x80 \| нибл` |
| `HAUSNUMMERN` | номера домов | после `ZE-NAMEN`: скорее всего, ссылается на те же имена |
| `LOCAL POIS` | точки интереса тайла | записи по 10 байт (x, y, атрибут) уже опознаны в `relocate.js` — нужен смысл атрибута |
| `RASTERINFOS` (тайловый) | внутренний индекс тайла | формат разобран (`src/raster.js`), нужен писатель |
| `LAYER 1 VERWEISE` | связь с грубыми уровнями | известна шапка; нужна таблица смещений и смысл байтовых серий |
| хвост записи в блоках v3, блоки v4 | геометрия грубых уровней | v3 читается и собирается байт в байт (`src/xacv3.js`); осталось содержимое хвоста у 9.6 % записей и весь v4 |
| поля `0x3e`, `0x44`, `0x48` шапки блока v5 и хвостовая область | последние 29.5 % байт при обратном проходе | сравнение блоков с известной местностью |
| код страны `0x3a` для Кипра | **минимум**: чем помечать свои блоки | реестр `COUNTRY` даёт `CY`, проверить на данных |

### Не форматы, но проверить обязательно

* **Читает ли устройство наши байты вообще.** Всё, что ставилось на машину, —
  заводские данные, сдвинутые в другое место. Ни одного сгенерированного нами
  блока `XAC` движок ещё не видел.
* **Собранный с нуля том `GDB`** на устройстве не ставился.
* **Сколько тайлов нужно Кипру и хватит ли доноров.** Число тайлов менять нельзя,
  пока `.xah` только правится на месте, — значит кипрское содержимое селится
  в чужие слоты. Не считали.
