# Разбор навигационной базы MMI 3G / 3G+

Реверс-инжиниринг формата навигационных данных Audi/VW MMI 3G(P) (вендор Becker
Automotive). Всё получено чтением файлов; оригиналы никогда не изменялись.

Разобранный набор: **8R0060884KL, ECE 6.36.0, «EUR 2023»**, 22 ГБ.
Для сверки привлекался второй набор: 8R0060884HS, ROW 5.13.4, покрытие
Австралия и Новая Зеландия (VW Touareg RNS 850).

## Состояние

| Что | Статус |
|---|---|
| Контейнер FLDB | разобран, пересобирается побайтно |
| Контрольные суммы | `CheckSum`, `check=qa`, сумма каталога FLDB опознаны и проверены сплошь; `checkcrc`/`fdefcrc` — нет, но на устройстве сверка базы выключена (`database checking is not enabled`) |
| Проекция | выведена и проверена на карте |
| Разделы .xac | разобраны |
| Блоки v3 | 20 из 20; корпус расширен до **29 045 записей** из 247 блоков. Структура слов середины: повторяющаяся группа `[связь 0xCxxx][0x8xxx][0x8xxx][мелкое]`, в конце терминаторы `0x4`/`0x0`. Слова `0x8xxx` — **данные, не ссылки** (разрешаются в узел 5.4% при 7.7% случайных). **Первое слово — класс дороги**: вскрыто сопоставлением с OSM, чем важнее дорога, тем меньше значение (primary 2–4, secondary 51–54, residential ~152, track 168). Второе слово и мелкое слово группы не вскрыты |
| Блоки v4 | 9 из 9, 100% байт |
| Блоки v5 | **дорожная сеть читается целиком** (`src/xacvec.js`): 92 128 рёбер по Праге, 85.8% вершин соединяют два и более ребра, медиана длины 30 м. Цепочка вектор → узел → координата замкнута и проверена: 11 926 из 11 926 координат попадают в рамку блока, 100%**. Векторы перечисляются: при `u16 +0x72 == 1` таблица смещений лежит по `u32 +0x6c`, число записей в `u16 +0x70`, смещение = запись × 2. Проверено на 39 блоках: цели попадают на метку `0xC0` в 78.7% против 14% случайных |
| Общий растр .ras, NACHBARN, XAC HEADER | разобраны |
| Зависание на 28% | **разгадано и вылечено**: после частичной установки пропадает `/HBpersistence/navi/db/acios_db.ini`; кладём его обратно (`tools/write_fixacios.sh`) — навигация поднимается. Данные ни при чём |
| Перенос тайлов на устройство | ставится без ошибок. Прежний вывод «виснет на любом сдвиге рамок тайла» **снят**: все те сборки были частичными установками и падали на пропавшем описателе, а не на данных |
| Сумма в каталоге FLDB | **взломана** (ndr FUN_0807a0b8): CRC-шаг 0x04C11DB7 + сложение, 0xC7; `relocate.js` пересчитывает |
| Сумма блока CIFF | тот же алгоритм; в тайлах/.xah не используется, только в прочих данных |
| GDB | шапка, 12 уровней, сетка кластеров L0 (`slot=cy·W+cx`), 19-байтные тайлы, заголовок блоба, поток элементов, кодирование точек и **реестр S1/S2** — разобрано и пишется (`src/gdb.js`, `src/gdbwrite.js`, `src/gdbroads.js`). **Каталог уровней разобран** (`FUN_08cb20f0`): в шапке 32 пары «смещение, размер», из них заполнены 12; у каждого уровня своя шапка с размером ячейки и диапазоном масштабов. Осталось: разбор сетки внутри грубых уровней, бит-упакованный вариант потока точек, секция S3 |
| Инициализация NDL | автомат разобран; `end: NDL Initialisation` печатается только из состояния 3 и оттуда — всегда, значит зависание сидит до него, в состоянии 0, 1 или 2. Какое именно — по журналу неразличимо: эти сообщения идут в отключённый канал |
| LIT…LIT4 и PIT | **база точек интереса**, один контейнер с магией `Lit\x02`. Каталог разобран и сходится с двух концов: у LIT 245 518 блоков по 7 байт (смещение 5 байт), 0 разрывов, конец ровно на сумме четырёх томов; у PIT 717 по 6 байт, конец ровно на размере файла (`src/lit.js`). Формат записей задаётся **грамматикой в блоке TTD** (`src/litschema.js`). Словарь сжатия имён читается, имена разворачиваются в настоящие названия (`src/litdict.js`). Машина грамматики написана (`src/litvm.js`) и проходит в среднем 7 % блока — стоит на связи «номер поля `w1` → поле кадра». Подробности в [docs/formats/lit.md](docs/formats/lit.md) |
| ATLAS (CTY/TER) | **контейнерный формат разобран**: разделы с именем и размером, сигнатура контейнера `0123456789abcdef…`, тип содержимого строкой. `TER` — 11 051 контейнер `SoarTerrain`, `CTY` — 2539 `Map` и один `Root`. Содержимое контейнеров не разбиралось. Прежде: опознаны магии (`Lit\x02`+`HBIS`; `\x06HEADER`+`Orion`+`Atlas`), не разбирались |

Разбираются все 40 векторных блоков во всех восьми проверенных тайлах. Узлов
после включения v5: Мальта 39 939, Андорра 15 531, Лихтенштейн 8 892,
Сан-Марино 6 816, Монако 1 760.

Проверка результата глазами: выгрузка Мальты в ASCII воспроизводит очертания
архипелага — Гозо на северо-западе, Комино между островами, главный остров
с уплотнением на юго-востоке у Валлетты.
